## Overview

The **Notification Service** is a lightweight, event-driven AWS Lambda worker responsible for processing asynchronous business events generated by the ArtCorner ERP backend.

The service consumes messages from an Amazon SQS FIFO Queue and dispatches notifications through:

- Amazon SNS
- Amazon SES

This architecture decouples transactional processing from notification delivery, improving scalability and reliability.

# Event Processing Workflow

The Lambda function is triggered automatically whenever new records arrive in the SQS FIFO queue.

## Main Processing Flow

### Step 1 — Receive SQS Records

`main.py` receives batched SQS messages from AWS Lambda's event source mapping.

### Step 2 — Extract Event Type

The service extracts:

```python
messageAttributes["eventType"]["stringValue"]
```

This value determines which handler should process the event.

### Step 3 — Route Event

`router.py` maps the event type to its corresponding handler.

Example:

```python
event_type = message["messageAttributes"]["eventType"]["stringValue"]
handler = router.resolve(event_type)
handler.handle(message)
```

# Supported Events

## OrderPlaced

### Workflow

- Formats order details
- Creates operational notification content
- Publishes alerts to the Employees SNS Topic

### Notification Channel

- Amazon SNS
- Operational alerts

---

## OrderUpdated

### Workflow

- Formats updated order information
- Generates customer-facing email content
- Sends transactional emails via Amazon SES

### Notification Channel

- Amazon SES
- Customer email notifications

---

## StockAlert

### Workflow

Triggered whenever inventory falls below the configured business threshold.

The handler:

- Generates inventory alert payloads
- Notifies administrators via SNS

### Notification Channel

- Amazon SNS
- Administrative alerts

|---|---|
